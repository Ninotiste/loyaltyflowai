# Politique de sécurité

Merci de contribuer à la sécurité de LoyaltyFlowAI.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique pour une vulnérabilité non corrigée.** Utilisez la fonction de signalement privé de vulnérabilité de GitHub (« Report a vulnerability ») depuis l'onglet Security du dépôt.

Si cette fonction n'est pas disponible, contactez le mainteneur via son profil GitHub en demandant un canal privé. Ne publiez pas de détails exploitables avant qu'un correctif soit disponible.

## Informations utiles

Incluez, si possible :
- les versions et composants concernés ;
- l'impact potentiel ;
- les étapes minimales pour reproduire le problème ;
- une proposition de mitigation, si vous en avez une.

N'envoyez jamais de mots de passe, tokens, clés API ou données personnelles dans un rapport.

## Périmètre

Les rapports concernant le code présent dans ce dépôt sont les bienvenus. Les services tiers (Supabase, Vercel, Stripe, etc.) doivent être signalés à leurs éditeurs respectifs lorsqu'ils sont seuls concernés.

Nous remercions les personnes qui signalent les problèmes de manière responsable.
