# Faire connaître LoyaltyFlowAI

Ce document sert de kit de présentation. Publiez uniquement dans des communautés où les projets open source et les demandes de retours sont autorisés. Respectez les règles de chaque communauté et personnalisez le message.

## Présentation courte

LoyaltyFlowAI est un projet open source de plateforme de fidélisation pour les restaurants indépendants. Le dépôt est en phase de fondation et cherche des retours de développeurs sur son architecture, ses tests et ses fonctionnalités.

Code : https://github.com/Ninotiste/loyaltyflowai

## Message proposé (anglais)

Hi! I'm building LoyaltyFlowAI, an open-source customer loyalty platform for independent restaurants, using TypeScript, Next.js, Prisma and PostgreSQL.

The project is still early, and I'd really appreciate feedback from developers interested in SaaS, restaurant tech, or open-source tooling. Contributions are welcome — especially documentation, tests, and small, well-scoped improvements.

Repository: https://github.com/Ninotiste/loyaltyflowai

Le projet est encore en phase de fondation. Je cherche des retours honnêtes sur l'architecture et des contributions concrètes : documentation, tests, corrections et petites améliorations.

## Où le partager

- Communautés GitHub et forums orientés open source / TypeScript.
- Communautés de développeurs web et SaaS qui autorisent les présentations de projets.
- Réseaux personnels ou professionnels, avec une demande de retour précise.

Évitez le spam, les messages privés non sollicités et les demandes de contributions artificielles. Ne promettez pas de récompense et ne demandez jamais aux gens de créer une PR sans changement utile.

## Suivi

Mesurez les résultats avec des retours, issues utiles et PR réellement fusionnées. Les étoiles, forks et comptes créés ne remplacent pas des contributions externes de qualité.
