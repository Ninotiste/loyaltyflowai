# FAQ – LoyaltyFlowAI

Cette page répond aux questions les plus fréquentes sur LoyaltyFlowAI.

## Questions générales

### Qu'est-ce que LoyaltyFlowAI ?

LoyaltyFlowAI est une plateforme de fidélisation destinée aux restaurants indépendants. Elle aide les établissements à mieux fidéliser leurs clients.

### À qui s'adresse la plateforme ?

Elle s'adresse principalement aux restaurateurs indépendants qui souhaitent mettre en place un programme de fidélité.

### Faut-il installer une application pour utiliser le widget client ?

Non. Le widget peut être intégré directement au site web du restaurant. Les clients peuvent ainsi consulter leurs informations sans installer d'application.

## Programme de fidélité

### Comment les clients consultent-ils leurs points ?

Les clients peuvent utiliser le widget installé sur le site du restaurant pour consulter leur solde de points.

### À quoi servent les points ?

Les points permettent aux clients d'accéder aux récompenses proposées par leur établissement.

### Tous les restaurants proposent-ils les mêmes récompenses ?

Non. Les récompenses dépendent du programme configuré par chaque établissement.
