# packages/ui — Composants UI partagés

Bibliothèque de composants basée sur **shadcn/ui** + Tailwind CSS.

Partagée entre `apps/web` et tout futur package nécessitant des composants UI.

→ [Design system](../../MASTER_PLAN.md#20-principes-ux)

## Contenu

- Composants shadcn/ui installés et configurés
- Composants custom propres à LoyaltyFlowAI
- Tokens de design (couleurs, typographie)

## Usage

```typescript
import { Button } from "@loyaltyflowai/ui"
import { Card } from "@loyaltyflowai/ui"
```
